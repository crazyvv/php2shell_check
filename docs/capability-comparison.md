# 与 murrez/php2shell 的能力对照

参考快照：2026-10-29，提交 `7de30d56887d20e4bfc1b3f90b47f067917742c7`，https://github.com/murrez/php2shell 。仅阅读源码与文档，没有运行其探测代码；以下实现为本项目独立编写，没有复制其利用载荷。

| 对方能力 | 本项目处理 |
| --- | --- |
| 单目标与批量评估 | 已有 CLI 单目标与页面最多 50 目标任务、全局/用户限流、当前用户隔离、管理员汇总 |
| 上传处理入口与表单发现 | 新增已有响应的有界表单提取、处理路径、文件字段与外部引用标识；不进行目录字典枚举或额外请求 |
| 上传及执行验证、扩展名绕过 | 不加入自动上传可执行代码、绕过或命令执行；页面提供鉴权、类型校验、隔离存储与执行权限复核建议 |
| SAPI 画像 | 已有主机进程、模块、PHP 命令与 Web 运行时报告；不凭 nginx/Apache 头推断 FPM/mod_php，不以故障请求识别 SAPI |
| 会话序列化处理器探测 | 新增 PHP 命令/Web 报告选定配置采集，以及响应已有错误文本识别；不操纵处理器、不污染会话 |
| OOM、worker 故障、时间异常 | 新增已有内存耗尽文本识别；不进行压力校准、堆喷射、worker 固定或故障注入；500/慢响应不能证明漏洞 |
| 自动 LFI 发现与利用链 | 新增已有文件包含错误分类供代码复核；不枚举敏感文件、不进行会话文件包含或远程命令执行 |
| 严格 CVE 分类 | 继续使用本项目已核对的官方基线；对方 README 新增 CVE-2026-115560 及 8.2.36/8.3.37/8.4.28/8.5.13 基线本次未获官方来源核验，不纳入判定 |
| 自适应、ASLR、FPM 两阶段利用 | 不加入；本项目通过实际实例、厂商包修订和进程重启证据辅助复核 |
| 进度、结果落盘、结构化导出 | 已有任务状态、SQLite、JSON/CSV、规则版本追踪与审计；新增表单/错误可视化与 JSON 字段 |
| 代理轮换、身份伪装与 TLS 跳过 | 不加入；继续范围校验、DNS 固定、TLS 校验及限流 |
| 技术识别 | 已有 51 条内置规则，管理员可维护特征 JSON，按提交任务固定规则快照 |

新增被动线索不会发送更多网络请求，不改变既有漏洞判定；发现表单、错误或序列化配置均不是漏洞确认。这里只覆盖能安全整合进开发团队共享扫描平台的能力，并未宣称完整复刻该利用框架。

本次尝试访问 CVE 官方记录时网络代理返回 403，未用社区声明替代官方证据。后续若有可核验的官方公告，应按各 CVE 独立维护适用条件与修复版本。

管理员可在后台管理在线配置、范围和检测权限；允许 multipart 后仍由开发者选择本次启用。配置和特征库均有持久化、冲突保护与审计。不会提供自定义可执行载荷或通用 HTTP 利用模板接口。
