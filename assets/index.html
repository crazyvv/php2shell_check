采集并导入主机报告

在目标 Linux 主机运行下方 Rust 命令并导入报告。批量巡检可直接获取 Bash 脚本。查看下载与使用说明可选功能默认关闭；Web 请求只面向已关联进程的本机监听端口，不能自动确认后端实例。普通用户权限不足时会显示未知或不完整。

命令在目标主机手工执行，不会从此页面远程执行。Web 开关需要中间件和端口开关，模块与端口开关需要中间件开关。容器与 TLS 证书限制见部署说明。
