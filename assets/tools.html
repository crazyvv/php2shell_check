主机工具与下载

将 Bash 脚本分发到目标主机执行。默认检查 Java4Shell、Nginx2Root 和 Apache2Root，无需指定目标或安装 Python。

下载 x2shell-check.sh

Bash 批量巡检

在每台目标主机运行，直接查看文本结果。

bash x2shell-check.sh

批量执行时可保存结构化结果。

bash x2shell-check.sh --all --json > host-audit.json

可通过 --java4shell、--nginx2root 或 --apache2root 单独检查。--all --jcmd 显式启用 JVM 诊断附加。

在 Linux 上可使用 /proc 核对运行实例。权限不足、容器隔离或系统缺少 /proc 时，可用证据会减少。

Rust 主机报告

需要核验 PHP 或上传主机报告时，在扫描页选择采集项，复制生成的命令到目标主机执行，再关联业务 URL 并导入 JSON。

x2shell-check collect > host-report.json

Bash 的 host-audit.json 供批量巡检留档。扫描页接受 Rust 采集生成的主机报告。
